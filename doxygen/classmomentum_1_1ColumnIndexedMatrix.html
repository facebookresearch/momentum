Detailed Description

template<typename MatrixType>
class momentum::ColumnIndexedMatrix< MatrixType >

View over a matrix that exposes a (possibly reordered) subset of its columns.

When constructed with a colIndices span, accessing column i of this view returns the underlying matrix's column colIndices[i]. This lets callers run QR on a column subset without copying the matrix. When constructed without indices, this is a thin pass-through to the wrapped Eigen reference.

Note
Holds an Eigen::Ref and a non-owning span — the underlying matrix and index buffer must outlive this view. The view is mutable: mutations through col() write back into the wrapped matrix.
