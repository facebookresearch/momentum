Detailed Description

template<typename T>
struct momentum::JointParametersT< T >

A vector describing joint parameters, of size numSkeletonJoints * kParametersPerJoint.

E.g. for a character body model with 159 joints, the joint parameters vector has size 159 * 7 = 1113. The 7 parameters per joint are ordered [tx, ty, tz, rx, ry, rz, sc].
