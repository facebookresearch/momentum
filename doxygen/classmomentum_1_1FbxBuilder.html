Detailed Description

Builder class for creating FBX files with multiple characters and animations.

FbxBuilder allows you to incrementally construct an FBX scene by adding skinned characters, rigid bodies, motions, and marker data. This is useful for creating scenes with multiple characters/objects in a single FBX file.

Note
addCharacter(), addRigidBody() and addAnimatedMesh() export each object under a unique name: the requested name (character.name, or the name argument of addRigidBody() and addAnimatedMesh()), with a numeric suffix when that name is already in use. The exported name is the object's name in the file. A renamed character's joint and attribute nodes get the FBX namespace "<exportedName>:" (loaders remove it when stripping namespaces), and its skinned mesh is "<exportedName>_mesh" instead of "body_mesh". A rigid body with an explicit name also gets the namespace. Pass the returned name as characterName to addMotion() and addMotionWithJointParams() to target that character; an empty characterName targets the character added from character.name that kept that name, or else the first one added from character.name. An animated mesh is not a motion target. loadFbxCharacters() reads every character and animated mesh back under its exported name.

A non-empty FileSaveOptions::fbxNamespace given to addCharacter() or addRigidBody() prefixes the name of every node in the saved file with "<namespace>:", as saveFbx() does. A file has one namespace, so a different non-empty namespace in a later call throws.

A file also has one frame rate. Each call that writes animation (addMotion(), addMotionWithJointParams(), addAnimatedMesh() and addMarkerSequence()) sets it, so the last such call wins, and the loaders read every motion at that frame rate: a motion written at another frame rate comes back resampled, with another frame count. Give every motion of a file the same frame rate.

Example usage:

FbxBuilder builder;
const std::string bodyName = builder.addCharacter(bodyCharacter);
builder.addMotion(bodyCharacter, fps, motion, {}, bodyName);
const std::string propName = builder.addRigidBody(propCharacter, "controller", 0);
builder.addMotionWithJointParams(propCharacter, fps, jointParams, propName);
builder.save("output.fbx");

Add an animated mesh (mesh node with per-frame transform, no skeleton).

Creates a standalone mesh node and animates its transform directly from the root joint parameters. This is for props/objects that should appear as a simple animated mesh without any skeleton hierarchy.

Parameters
characterThe character providing the mesh geometry.
nameRequested name for the mesh node.
fpsAnimation frame rate in frames per second.
jointParamsJoint parameters with shape (nJointParams x nFrames), one column per frame. Only the first joint's rows are used: tx, ty, tz, rx, ry, rz and, if present, the scale (unit scale without it). Fewer than 6 rows throws.
userPropertiesUser-defined properties to write onto the mesh node, surfaced by DCC tools as the object's custom attributes.
Returns
The unique name the mesh node is exported under (see the class notes).

Creates a standalone mesh node and animates its transform from joint parameters. The joint params follow momentum convention: 7 values per joint (tx, ty, tz, rx, ry, rz, sc). Only the first joint's parameters are used (root transform).

jointParamsJoint parameters with shape (nJointParams x nFrames), one column per frame. Only the first joint's rows are used: tx, ty, tz, rx, ry, rz and, if present, the scale (unit scale without it). Fewer than 6 rows throws.
translationOffsetRest-pose translation offset added to the translation channels (defaults to zero).

Add model-parameter animation for a previously added character.

Converts model parameters to joint parameters via CharacterState, then creates animation curves. Also extracts and animates blend shape weights when the character has blend shapes. A joint parameter that no model parameter drives gets a curve when its value is not zero, such as an offset from offsets. A later call for the same character replaces its motion; a motion without columns writes nothing and keeps the earlier one.

Parameters
characterThe character to animate (must match a previously added character).
fpsAnimation frame rate in frames per second.
motionModel parameters with shape (nModelParams x nFrames), one column per frame. The number of rows must be character.parameterTransform.numAllModelParameters(); otherwise the function throws.
offsetsIdentity/offset joint parameters, added to the joint parameters of every frame. When its size is not numJointParameters(), the offsets of the character's earlier motion are used, as GltfBuilder does, or the bind pose (zero) if there is none.
characterNameName returned by addCharacter() or addRigidBody() of the character to animate. When empty, the character added from character.name that kept that name, or else the first one added from character.name; throws if there is none.
