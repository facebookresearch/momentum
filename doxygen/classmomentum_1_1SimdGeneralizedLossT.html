Detailed Description

template<typename T>
class momentum::SimdGeneralizedLossT< T >

SIMD (vectorized) variant of GeneralizedLossT that operates on DrJit Packet<T> lanes instead of individual scalars.

See GeneralizedLossT for the full mathematical description, the meaning of alpha and c, and the alpha-value reference (L2, L1/pseudo-Huber, Cauchy, Geman-McClure, Welsch).

Inherits the scalar value() / deriv() overloads and the cached lossType_ / invC2_ state from the base class. Branching on the loss type is uniform across all packet lanes (alpha is fixed at construction), so no per-lane masking is needed in the implementation.

When to use
Use this class inside SIMD error functions that process multiple constraints in a single packet (e.g., Simd*ErrorFunction). For scalar error functions or one-off evaluations, prefer the base GeneralizedLossT directly.
Thread safety
Instances are immutable after construction (all state is const in the base class), so concurrent reads from multiple threads are safe. Each evaluation is stateless.
