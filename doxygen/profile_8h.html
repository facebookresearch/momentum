Detailed Description

Profiling macros that dispatch to one of three backends, selected at compile time:

  • XR Profiler when MOMENTUM_WITH_XR_PROFILER is defined (forwards to XR_PROFILE_* from arvr/libraries/profile_redirect/annotate.hpp).
  • Tracy when MOMENTUM_WITH_TRACY_PROFILER is defined (forwards to Tracy's ZoneScoped / ZoneNamedN / FrameMark, etc.).
  • No-op otherwise: every MT_PROFILE_* macro expands to nothing, so instrumentation can be left in source with zero runtime cost.

All macros are safe to use unconditionally in library code; the active backend is determined entirely by the build configuration.
