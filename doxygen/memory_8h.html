◆ MOMENTUM_DEFINE_POINTERS

#define MOMENTUM_DEFINE_POINTERS ( x)
Value:
using x##_p = ::std::shared_ptr<x>; \
using x##_u = ::std::unique_ptr<x>; \
using x##_w = ::std::weak_ptr<x>; \
using x##_const_p = ::std::shared_ptr<const x>; \
using x##_const_u = ::std::unique_ptr<const x>; \
using x##_const_w = ::std::weak_ptr<const x>;

Define the standard set of smart-pointer type aliases for type x.

Generates six aliases following the project naming convention:

  • x##_p — std::shared_ptr<x>
  • x##_u — std::unique_ptr<x>
  • x##_w — std::weak_ptr<x>
  • x##_const_p — std::shared_ptr<const x>
  • x##_const_u — std::unique_ptr<const x>
  • x##_const_w — std::weak_ptr<const x>
Precondition
x must be a previously declared (or forward-declared) type name.

◆ MOMENTUM_FWD_DECLARE_TEMPLATE_CLASS

#define MOMENTUM_FWD_DECLARE_TEMPLATE_CLASS ( x)
Value:
template <typename T> \
class x##T; \
using x = x##T<float>; \
using x##d = x##T<double>; \
MOMENTUM_DEFINE_POINTERS(x) \
MOMENTUM_DEFINE_POINTERS(x##d)

Forward-declare a single-template-parameter class x##T and define float/double instantiation aliases plus their smart-pointer aliases.

Uses the project's backward-compatible naming scheme:

template <typename T> class BarT;
using Bar = BarT<float>;
using Bard = BarT<double>;

Smart-pointer aliases are generated for both Bar and Bard (e.g. Bar_p, Bard_p, ...).

Precondition
x##T must be a class template with exactly one type parameter.
