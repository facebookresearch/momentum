Detailed Description

template<typename T>
class momentum::ExportedNameRegistry< T >

Entries of a scene builder keyed by their exported (unique) name.

FbxBuilder and GltfBuilder export each character under a unique name and return it, so callers can target one exported character even when several share a source name (character.name). An empty requested name resolves to the entry added from the source name that kept that name, or else to the first entry added from the source name, which keeps calls that do not pass the returned name working. A character exported under the empty name is thus reachable with that name.
