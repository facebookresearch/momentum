Detailed Description

template<typename T>
class momentum::OrientationRotDiffErrorFunctionT< T >

The OrientationRotDiffErrorFunction minimizes the F-norm of (R_target^T * R_current - I), the rotation difference relative to identity.

Compared to OrientationErrorFunctionT which uses element-wise subtraction (R_current - R_target), this formulation computes the error in the tangent space of the rotation group, which is invariant to the choice of coordinate frame.
