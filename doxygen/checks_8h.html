Definition exception.h:55

Runtime check macros with two interchangeable backends:

  • When MOMENTUM_WITH_XR_LOGGER is defined, failures are reported via the XR logger's XR_CHECK family (which typically logs and aborts).
  • Otherwise, failures throw a std::runtime_error via MT_THROW_IF. The trailing variadic arguments are an optional fmt-style message and its format arguments. Asserts that condition is true; on failure, throws std::runtime_error with the optional fmt-style message.
